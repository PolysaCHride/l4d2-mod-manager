# UI 重构 · 设计原则

> 这一条约束后面所有关卡。任何新组件先对着这四条过一遍，过不了就改布局，而不是加说明文字。

## 一句话

**目标简单、架构简单、设计简单、实现简单。**

参照：Linear 官网的克制、Apple Notes 的秩序。不是"少放东西"，而是**每个像素只服务一件事**。

## 四条硬规则

### 1. 砍掉解释性文字

不写标语、不写提示、不写次要标签。

- ❌ `LOCAL MOD COMMAND`、`LIBRARY INDEX`、`SELECTED / 001`、`SOURCE HEALTH`
- ❌ `点击卡片查看详情，Enter 启用当前模组，Space 快速切换`
- ❌ `同组仅保留一个启用项 · 游戏内附加内容菜单已同步`
- ❌ 卡片上的 `角色 / Ellis`（已在 FilterPanel 表达）
- ❌ 未启用卡片上的 `未启用` 徽章（没有徽章就是未启用）

**如果一个页面非得靠这些才看得懂，那就是布局错了。**

### 2. 一个区域只做一件事

| 区域 | 唯一职责 |
|---|---|
| 01 TitleBar | 品牌 / 搜索 / 工作区切换 / 启动 |
| 02 Rail | 一级分类 |
| 03 FilterPanel | 当前范围的下一层筛选 |
| 04 MainHeader | 我在哪 + 我在看什么 |
| 05 ActionBar | 结果集的操作 |
| 06 ModGrid | 内容 |
| 07 Inspector | 选中项的状态与操作 |

状态筛选只在 FilterPanel，搜索只在 TitleBar，主操作按钮跟内容走——不跨区重复。

### 3. 操作跟着对象走

- 导入的「加入模组库」直接跟在解析列表下方（右侧对齐），不放页面底部操作条。
- 下载的「开始下载」同理。
- 卡片的所有操作（打开文件夹 / 工坊页 / 别名 / 分类 / 合集 / 删除）全部进 Inspector 底部图标行，不再有右键菜单。

### 4. 三端同时受益

每个决定都要同时提升：

- **UX**：用户少找、少读、少犹豫。
- **DX**：一个组件一个职责，样式只用 token，改版时不用全量翻代码。
- **AX**：DOM 结构即语义（`data-view` / `data-rail` / `data-pane`），选择器稳定，不靠位置和文案定位。

## 本轮落地

| 变更 | 为什么 |
|---|---|
| 工作区 tab 移到 01 | 全局切换属于顶层，不该藏在主区 |
| ActionBar 只留 4 项 | 状态筛选已在 03；不需要批量模式 |
| 主按钮跟列表 | 减少一次长距离视线移动 |
| 右键菜单并入 Inspector | 一个对象的所有操作只有一处 |
| 删除全部标语 / 提示 / 次要标签 | 靠布局表达，不靠文字解释 |
| 卡片无"未启用"徽章 | 默认态不占视觉预算 |
| 面包屑只读 | 导航已由 Rail + FilterPanel 承担 |

## 没有破坏的东西

- 保留：启用/停用、同组互斥、一键整理、工坊下载、压缩包导入、地图合集、回收站。
- 保留：键盘 `Ctrl K`、`Enter`、`Space`。
- 布局在 1440 / 1280 / 1100 三档均无横向溢出。

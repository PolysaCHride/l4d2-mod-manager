## 关于「整理规则」

这个词来自 V1 样稿，是我在页头放的一个按钮，**当前代码里没有对应功能**。

预览里它已经被移除，现在页头只有三个工作区 tab。真正和“整理”有关的现有功能只有：

- **一键整理**（原「一键管理」）：递归扫描 addons，把 workshop 里的 mod 移出、收拢子目录、补记未登记项、处理冲突外观组。
- **合集归组**：把地图模组归入工坊合集。

如果你想要的是“手动调整冲突规则 / 指定每组保留哪个”这类能力，那是一个新功能，需要单独设计，不是重构。

## 关于「ActionBar 只留视图 / 排序 / 刷新，够不够」

这是在问：移除状态筛选后的那一行，是否还漏了必要操作。当前保留四项，另外三个候选是：

1. **批量选择**：多选后批量启用 / 停用 / 删除。如果模组量大，这项很有用。
2. **扫描 / 导入入口**：现在导入已经变成 tab，不再需要按钮。
3. **当前筛选摘要**：例如「Ellis · 已启用」这样的可清除条件。

我的判断：先保持四项；如果后面确认需要多选，再加一个「选择」按钮进入批量模式。

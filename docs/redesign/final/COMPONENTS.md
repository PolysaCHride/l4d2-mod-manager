# BLACKSITE · 组件落地顺序

> 规则：每次只推进一个组件。先对齐需求，再做隔离预览；你确认后才进入最终页面。不会一次性重排整个界面。

## 已完成 · Foundation

- 布局基线：BLACKSITE。
- 色板层：`tokens.css` 中的 `blacksite` / `safehouse` / `workshop` / `index`。
- 色彩语义：canvas / surface / raised / border / text / accent / success / warning / danger / focus。
- 组件只消费 token，不硬编码 palette hex。

## 第 1 件：TitleBar（已按需求更新，待样式确认）

**已更新到 [preview.png](preview.png) / [preview.html](preview.html)。**

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ [新图标] L4D2 // ARMORY   [ 搜索模组…          Ctrl K ]   游戏未运行 [启动游戏] ─ □ × │
│         LOCAL MOD COMMAND                                                     │
└──────────────────────────────────────────────────────────────────────────────┘
```

**已确认**

- 保留：品牌 / 全局搜索 / 游戏状态 / 启动游戏 / 窗口按钮。
- 移除：标题栏通知、设置、头像。
- 品牌标题保留英文 `L4D2 // ARMORY`。
- 搜索左边界严格对齐 04 / 05 / 06 主区左边界，即 `x = 324`。
- 启动游戏使用全局酸绿色 `--accent` 底色。
- 新图标来自 icon session，已加入所有实时预览。
- 通知模型：与旧版一致，使用阻塞弹窗；不做通知中心、不做铃铛、不做 toast 正式通知。
- 搜索宽度 `clamp(320px, 32vw, 480px)`。

**还没定**

1. 继续自绘窗口还是改回 Windows 原生标题栏。
2. 1100px 下副标题与搜索的最终收缩规则。

**验收标准**

- 1440 / 1100 宽度下不换行、不溢出，所有按钮可点击。
- `Ctrl + K` 可聚焦搜索；`Esc` 清除焦点。
- 搜索字段、主标题、工具条、卡片网格共享同一条左侧基准线。
- 图标按钮都有可访问名称；键盘焦点可见。
- 游戏状态覆盖：未运行、运行中、游戏目录缺失。

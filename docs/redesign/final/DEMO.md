# 可交互演示 · 使用说明

> 入口：[demo.html](demo.html)  
> 这是一个纯前端演示：没有后端、不读写真实文件，所有数据在内存里。
> 它的作用是让你逐项检查交互、状态与文案，而不是替代 Qt 实现。

## 能操作什么

| 区域 | 可以做的事 |
|---|---|
| 01 TitleBar | 搜索、切换工作区（浏览 / 导入压缩包 / 链接下载 / 设置）、模拟游戏运行状态、窗口按钮 |
| 02 Rail | 切换 全部 / 角色 / 特感 / 武器 / 地图 / 其他；在任务视图点击会自动回到浏览；「整理」触发扫描 |
| 03 FilterPanel | 状态筛选（全部 / 启用 / 停用）、物品选择、可折叠分组、冲突提示；「全部」下展开所有子分类 |
| 04 MainHeader | 面包屑与标题随 Rail 与物品选择变化 |
| 05 ActionBar | 网格 / 列表切换、排序、刷新 |
| 06 ModGrid | 单击卡片选中并在 Inspector 显示；**双击切换启停（双向）**；启用态为方案 C（整卡荧光绿 + 黑描边 + 外圈光环） |
| 07 Inspector | 启用 / 停用（含同组互斥确认）、设置别名、同组跳转、更多菜单、删除确认 |
| 08 StatusBar | 扫描进度实时推进；完成后回到就绪 |

## 建议的检查路线

1. **浏览**：切到「武器」，展开/收起「近战」，确认折叠与缩进。
2. **双击启停**：在「角色」里双击一张未启用的卡片 → 整卡变荧光绿、文字转黑；再双击一次恢复。同组有启用项时会先弹确认。
2b. **互斥**：点卡片 → Inspector 打开开关 → 同样会出现「切换同组外观」确认窗。
3. **别名**：Inspector 底部第一个图标 → 输入别名 → 标题变成别名、原名作为次标题。
4. **导入**：切到「导入压缩包」→ 点击拖放区 → 解析进度 → 列表（含「已在库」禁用行）→ 加入模组库。
5. **下载**：切到「链接下载」→ 粘贴任意工坊链接 → 解析 → 勾选 → 开始下载（日志常驻）。
6. **锁定**：设置里打开「游戏运行状态」→ 回浏览页启用任意模组 → 出现「游戏运行中」拦截。
7. **扫描**：点「整理」→ 确认 → 看状态栏进度条推进。
8. **1100 宽**：把窗口拉窄，确认顶部 tab 只留图标、卡片降为两列、无横向滚动。

## 与真实应用的差异（重要）

| 项目 | 演示页 | 真实应用 |
|---|---|---|
| 文件读写 | 纯内存 | 读写 `addons/`、`addonlist.txt` |
| 工坊解析 | 固定返回两条 | 调用 Steam Web API |
| 下载 | 定时器模拟 | file_url 直连，失败切换 SteamCMD |
| 压缩包解析 | 固定返回三条 | 调用 7-Zip 解压 + VPK 解析 |
| 删除 | 直接从内存移除 | 移入 `data/trash/` 回收站 |
| 窗口按钮 | 只弹提示 | 真实最小化 / 最大化 / 关闭 |
| 设置项 | 只有游戏状态开关生效 | 全部生效 |

## 文件

```text
demo.html   结构（含内联 SVG 图标）
demo.css    样式，只使用 tokens.css 的语义变量
demo.js     数据与交互逻辑
```

修改样式时优先改 `tokens.css`，不要在 `demo.css` 里写死颜色——这一点和最终的 Qt 实现要保持一致。

## 已知取舍

- Inspector 只在「浏览」视图出现；导入 / 下载 / 设置是任务视图，右侧不留详情面板。
- 任务视图不显示页面大标题，因为面包屑已经说明位置，标题只会重复顶部 tab。
- 状态筛选只在 FilterPanel，ActionBar 不再有 chips。
- 别名是主标题、原名是次标题；卡片上同样如此。
- 「归入合集」只在 `分类 = 地图` 的模组出现。

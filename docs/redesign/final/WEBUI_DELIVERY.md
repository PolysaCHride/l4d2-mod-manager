## 三、已实现的功能

### 浏览（完整）
- 6 个一级分类（全部/角色/特感/武器/地图/其他）
- 状态筛选（全部/启用/停用）、物品筛选、分组折叠
- 单击选中 → Inspector；**双击切换启停**（含同组互斥确认）
- 网格 / 列表切换
- 搜索
- Inspector：启用开关、别名（主标题）、分类、合集、删除、打开文件夹/工坊

### 长任务
- **扫描**：进度条实时推进，完成刷新列表
- **导入压缩包**：原生文件选择 → 解析进度 → 候选列表（标「已在库」）→ 写入进度 → 完成
- **链接下载**：解析链接 → 取工坊详情（含合集展开）→ 勾选 → 下载进度 + 常驻日志 → 结果

### 设置
- 游戏目录（自动检测 / 手动选择）
- 代理保存
- 清理缓存（真实释放字节数）
- 检查更新（GitHub releases）

### 无边框窗口
系统标题栏已移除，顶栏由页面自绘：
- 拖动：顶栏加了 `pywebview-drag-region` 类，只有这块能拖
- 最小化 / 最大化 / 关闭：接真实窗口 API
- 圆角 8px，最大化时自动取消
- 边缘缩放保留

### 首次使用
空库时显示「开始整理」按钮，点击直接触发真实扫描。已验证：`boot mods=0` → 引导显示。

### 配色
`set_palette()` 后端入口已就绪，前端不暴露切换 UI。

## 四、踩过的坑（都已修复）

| 问题 | 原因 | 修复 |
|---|---|---|
| 打包后 JS 完全不执行 | `bridge.js` 里 `hasPy` 函数被误删 | 补回 |
| pywebview api 未注入 | `Object.keys` 判断时机太早 | 事件 + 轮询双保险 |
| 全部缩略图裂图 | `file://` 跨盘符被 WebView2 拦截 | 改为 data URI |
| 时间显示「2965 天前」 | 秒级时间戳当毫秒用 | 单位换算 |
| 卡片标题撑破 | 长标题不限行 | `-webkit-line-clamp: 2` |
| 打包体积 454MB | 用了 QtWebEngine | 换 pywebview（29MB） |
| `console=False` 后无输出 | 诊断需要 | 加 `api.log()` 写文件 |

**最有价值的一条**：所有这些都是**只有真跑起来才会发现**的。数据层验证通过 ≠ 界面正确。

## 四点半、本轮修复（第二轮反馈）

| # | 问题 | 处理 |
|---|---|---|
| 1 | 冲突弹窗超出页面 | 弹窗限高 + 内部滚动条 |
| 2 | 点空白处不能关闭弹窗 | 遮罩和留白都响应关闭 |
| 3 | Inspector 同组切换无确认 | 与 Mod Grid 双击走同一套互斥确认 |
| 4 | 更多菜单需要再点一次才收起 | 点外部 / 滚动 / ESC 都自动收起 |
| 5 | **冲突检测误报** | **只对互斥类别（角色/特感/枪械/近战/医疗品/投掷）判定，地图和脚本不再误算** |
| 6 | 树状分类箭头不够醒目 | 细线条换成实心三角，尺寸 12→14px |
| 7 | 分类排序 | 「全部X」置顶，「未指定」第二，其余按数量降序 |

### 顺带发现的严重问题

**FilterPanel 整个是演示数据写死的。** 真实库有 23 个枪械模组，界面只显示 AK-47 和 M16A2 两个假物品，其余全被藏起来。

已改为**从真实数据动态推导分类树**：
- 一级分类固定
- 二级物品实时从 `MODS` 生成
- 验证：武器分类现在显示 52 个模组、4 个分组、44 个物品行

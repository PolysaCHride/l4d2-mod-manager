03 / RULES

使用规则

先把颜色的职责定清楚，再开始做组件；否则每加一个组件都会重新讨论“这个绿是主色还是成功”。

01

主色只做信号，不做底色

Acid green、安全红、亮青、品牌红都只承担焦点、启用、主操作和选中态。大面积背景始终留在 canvas / surface。

02

状态色与主色分离

BLACKSITE 的主色是绿，但成功态使用 --success；WORKSHOP 的主色是蓝，成功态仍使用独立绿色。不要让“主色”替代语义。

03

浅色板用暖中性色

SAFEHOUSE / INDEX 不直接使用纯灰：前者偏纸黄，后者偏冷白。中性与文字对比先满足可读性，再追求气质。

TOKEN CONTRACT / 组件层

组件不写颜色。

按钮、卡片、开关、状态条、标签都只用语义变量。换配色时不碰组件实现；新增组件前，也必须先确认它使用哪些 token。

background: var(--surface);
color: var(--text-primary);
border: 1px solid var(--border-subtle);
outline-color: var(--focus-ring);
OPEN DECISION / 待确认

这四套色板怎么用？

建议：BLACKSITE 作为默认；另外三套先作为“命名色板”沉淀在 token 层，不急着做主题切换 UI。等布局确认后，再决定是否开放为运行时主题。

data-palette="blacksite" | "safehouse" | "workshop" | "index"

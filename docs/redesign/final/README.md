## 演示页检查清单

1. **浏览** — 切到「武器」，展开/收起「近战」，看折叠与缩进
2. **互斥** — 角色 → 点未启用卡片 → Inspector 开关 → 「切换同组外观」确认窗
3. **别名** — Inspector 底部第一个图标 → 输入别名 → 主标题变别名、原名变次标题
4. **导入** — 顶栏「导入压缩包」→ 点拖放区 → 解析 → 列表（含「已在库」）→ 加入模组库
5. **下载** — 顶栏「链接下载」→ 粘贴链接 → 解析 → 勾选 → 开始下载（日志常驻）
6. **锁定** — 设置里打开「游戏运行状态」→ 回浏览页启用 → 「游戏运行中」拦截
7. **扫描** — Rail「整理」→ 确认 → 状态栏进度条推进
8. **1100 宽** — 拉窄窗口，tab 只留图标、卡片两列、无横向滚动

详细说明见 [DEMO.md](DEMO.md)。

## 已确认的设计决定

| 项 | 结论 |
|---|---|
| 布局 | BLACKSITE，四区 + 右侧详情 |
| 色板 | BLACKSITE 默认；SAFEHOUSE / WORKSHOP / INDEX 沉淀为命名色板 |
| 一级导航 | 全部 / 角色 / 特感 / 武器 / 地图 / 其他 |
| 合集 | 不设一级入口，只作为地图里的文件夹 |
| 一键管理 | 更名「一键整理」 |
| 工作区 | 浏览 / 导入压缩包 / 链接下载（+ 设置），放在 01 顶栏 |
| 搜索 | 只有顶部一个，左边界与主区对齐 |
| 状态筛选 | 只在 FilterPanel |
| 卡片点击 | 只在 Inspector 展示，无独立详情窗 |
| 右键菜单 | 全部并入 Inspector |
| 别名 | 主标题；原名作次标题 |
| 归入合集 | 仅地图类模组显示 |
| 通知 | 全部用阻塞弹窗，不做通知中心 |
| 退订提示 | 纯提示，不做任何跳转 |
| 下载日志 | 常驻显示 |
| 状态栏 | 就绪 / 扫描中（带进度条）/ 异常；导入下载用自己的进度 |
| 批量选择 | 不做 |
| 「全部」筛选栏 | 展开所有子分类，每个分类一组 |
| Rail 跨视图 | 在导入/下载/设置页点分类，自动切回浏览 |
| 卡片双击 | 双向切换启停（与 Inspector 开关走同一套逻辑） |
| 启用态卡片 | **方案 C**：整卡荧光绿 + 2px 黑描边 + 外圈 1px 光环，文字黑 |
| 入库字段 | 显示为「入库时间」 |

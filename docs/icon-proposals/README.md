# L4D2 Mod Manager · 图标重绘方案 01–05

五版都遵循同一条约束：**透明背景，只有生物危害标志由小圆角方形像素点组成**。
没有底板、没有外框、没有第二色；红色是唯一彩色。

## 最终选择（2026-11-18）

已选定：**V2 的 40 格点阵布局 + V3 的上亮下暗三段渐变**。
`assets/` 已替换为这一版，合成文件在 `final/`。

- **48px 起**：严格使用 V2 的 40 格点阵、点距 14%、圆角 34%、符号宽 90%，套 V3 渐变。
- **16/24/32px**：使用同轮廓、同渐变的实心 hinted 版。40 格点阵在这些尺寸下没有完整像素，整体最大 alpha 只有约 50%，任务栏会发灰；实心 hinted 能保证可读性。
- **48px** 的点阵最大 alpha 为 185（约 73%），因为 1px 点仍无法完全覆盖像素；64px 起为 255。
- 如果希望 16/24/32px 也严格保留点阵，可以换回点阵小尺寸，但会更淡。

最终预览：[深色背景](final/preview-dark.png) · [浅色背景](final/preview-light.png)。

## 怎么选

| 版本 | 一句话 | 适合 |
| --- | --- | --- |
| **V1 标准点阵** | 44 格实心红，密度和点感最平衡 | 想要一个稳妥、耐看、不抢 UI 的默认图标 |
| **V2 大点警示** | 40 格、点更大更圆、红更亮 | 最看重任务栏/小尺寸识别度，想要“警示牌”气质 |
| **V3 细点渐变** | 56 格细点，上亮下暗三段渐变 | 大尺寸展示多、喜欢精致和光感 |
| **V4 双色描边** | 48 格，亮红描边 + 深红内芯，双色浮雕感 | 想要更技术、更有“描边/扫描”识别度 |
| **V5 半调点** | 44 格，点径随轮廓覆盖率变化 | 喜欢柔和、铜版网点/印刷质感 |

个人建议：**V1 最稳，V2 最实用**。如果只装一个，我会先看 V1；如果经常在 16–32px 的任务栏里出现，V2 更清楚。

## 小尺寸说明

16/24/32px 已使用实心渐变 hinted，48px 起才显示点阵。点阵在 32px 以下无法形成完整像素，
强行保留会让任务栏图标整体发灰；这是图标设计的常规 hint 处理。
如果你更希望小尺寸也严格保留点阵，我可以换回点阵版，但对比度会下降。
